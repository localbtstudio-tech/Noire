## ◼︎ The Concept

NOIRÉ is a **luxury fashion editorial website** built around one idea:

> **Turn scrolling into an experience.**

Instead of a conventional vertical landing page, NOIRÉ uses a cinematic horizontal journey combining **typography, photography, motion, and storytelling**.

Every section is designed to feel like a page from a high-end fashion magazine.

## 🎞️ Motion

The heart of NOIRÉ is its animation system.

**Vertical scrolling → Horizontal movement**

```text
User Scroll
     │
     ▼
   Lenis
     │
     ▼
ScrollTrigger
     │
     ▼
    GSAP
     │
     ▼
Horizontal Experience
```

The interface also uses:

* Smooth image reveals
* Parallax movement
* Typography animations
* Section transitions
* Hover interactions
* Custom cursor effects

---

## 🖤 Visual Direction

NOIRÉ follows a deliberately restrained visual language:

**Dark.**

**Minimal.**

**Editorial.**

**Cinematic.**

The design combines:

* `Playfair Display` — editorial serif
* `DM Sans` — modern sans-serif
* High-contrast imagery
* Deep black surfaces
* Subtle borders
* Large typography
* Generous whitespace
